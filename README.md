# ML-Week: Naive Bayes and SVM for Spam Classification

Welcome to the **ML-Week_NB-and-SVM** repository! This project contains the materials and code for a Machine Learning workshop presenting the Support Vector Machine (SVM) and Naive Bayes algorithms to classify emails into spam and not spam.

## 🚀 Overview & Features

* **Email Spam Classification:** Practical application of SVM and Naive Bayes algorithms to process and categorize email data effectively as either spam or legitimate.
* **PyTorch Polynomial Regression:** In addition to classification tasks, the repository includes a custom PyTorch class named `PolyRegression` that inherits from `torch.nn.Module`. This module efficiently calculates polynomial regression using matrix operations, which is significantly faster than using loops, especially for higher degrees and larger datasets.

## 📂 Repository Contents

* **Classification Models:** Implementations of the SVM and Naive Bayes classifiers for the email dataset.
* **Coding and Development:** Please reference the file named "Coding and Development" verbatim for more detailed guidelines, scripts, and developmental notes related to this workshop.
* **PyTorch Modules:** Neural network models built using PyTorch, demonstrating forward pass definitions, input transformations, and proper module initialization.
